# 📘 Sixth Semester Notes Repository

Welcome to the **Sixth Semester Notes Repository**. This repository is created to help students easily access, manage, and stay up to date with **sixth semester academic notes in PDF format**. The content is structured subject-wise and is continuously updated throughout the semester.

---

## 🎯 Purpose of This Repository

* Provide **centralized access** to sixth semester notes
* Ensure **easy sharing and collaboration** among students
* Allow **quick updates** without re-downloading all files
* Maintain a **clean and organized structure** for academic material

---

## 📂 Repository Structure

* 📁 **Subject-wise folders**
* 📄 **PDF notes** for each subject
* 🔄 **Regular updates** as new material is added
* 🗂️ Logical and easy-to-navigate folder hierarchy

---

## 🚀 How to Access the Notes

You can access the notes using **two methods**. Choose the one that best fits your needs.

---

## ✅ Method 1: Download ZIP (Simple & Quick)

Best for users who do not want to use Git.

### Steps:

1. Click the green **Code** button on the repository page
2. Select **Download ZIP**
3. Extract the downloaded ZIP file
4. Open and read the PDF notes

⚠️ **Note:** If new notes are added or existing ones are updated, you will need to download the ZIP file again.

---

## ✅ Method 2: Using Git (Recommended for Regular Updates)

This method is ideal if you want to **keep your notes updated automatically** without downloading everything again.

---

## 🧰 Step 1: Install Git

Download Git from the official website:

👉 [https://git-scm.com/downloads](https://git-scm.com/downloads)

Install Git using the **default settings**.

---

## 📥 Step 2: Clone the Repository (First Time Only)

Open **Command Prompt / Terminal** and run:

```bash
git clone https://github.com/ankitera1136/sixth_semester.git
cd sixth_semester
```

This will download the repository to your local system.

---

## 🔄 Step 3: Update Notes (Whenever New Notes Are Added)

Whenever you want the latest notes, simply run:

```bash
git pull
```

Only the **new or updated files** will be downloaded.

---

## 💡 Advantages of Using Git

* No need to re-download all notes
* Faster updates
* Easy version tracking
* Ideal for the entire semester

---

## 📌 Important Notes

* Do not modify file names or folder structure unnecessarily
* Always run `git pull` inside the repository folder
* Make sure you have an active internet connection while updating
